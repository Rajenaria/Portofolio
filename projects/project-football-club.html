01 / UI UX DESIGN

Football Club Website – Interactive UI/UX Prototype

Sebuah project perancangan prototype interaktif website klub sepak bola yang dibuat menggunakan Figma sebagai bagian dari mata kuliah Interaksi Manusia dan Komputer. Website ini dirancang untuk menyediakan berbagai informasi mengenai klub seperti jadwal pertandingan, squad pemain, Man of the Match, berita, serta informasi pertandingan. Selain sebagai media informasi, prototype ini juga memiliki fitur pembelian tiket pertandingan dan merchandise seperti jersey. Pengguna dapat memilih produk, memasukkannya ke keranjang, mengisi data checkout, hingga melakukan simulasi penyelesaian transaksi melalui alur yang telah dirancang. Setiap tombol, navigasi, dan halaman pada prototype telah dihubungkan menggunakan fitur prototyping di Figma sehingga pengguna dapat mencoba alur penggunaan website secara langsung. Project ini berfokus pada penerapan UI/UX Design, User Flow, Information Architecture, Interaction Design, serta prinsip Human-Computer Interaction untuk menghasilkan antarmuka yang intuitif, terstruktur, dan mudah digunakan.
