The Challenge

Lab equipment is stationary, expensive, and isolated.

Traditional potentiostats used for electrochemical analysis are bulky desktop machines costing thousands of dollars. Researchers in environmental monitoring and point-of-care diagnostics require field-ready devices that can collect precise analog data and immediately upload it for remote analysis without relying on a dedicated laptop.

The Solution

A fully connected edge-to-cloud analytical instrument.

I designed a custom PCB combining precision analog front-end (AFE) components with an ESP32 microcontroller. This handheld device performs cyclic voltammetry, digitizes the signal, and transmits it via WiFi/MQTT to a custom Node.js backend, visualizing the chemical reactions in real-time on a React dashboard.

Cost reduced by 95%

The Process

Engineering the System

A step-by-step breakdown of designing the hardware, programming the firmware, and building the web architecture.

PHASE 01

Analog Hardware Design

The core challenge was translating a chemical reaction into a readable digital signal. I designed a transimpedance amplifier (TIA) circuit to convert nano-ampere currents from the sensor into measurable voltage, feeding it into a 16-bit ADC.

KiCad Op-Amps LMP91000
> Noise reduction was critical. Implemented a driven-shield approach and star grounding on the 4-layer PCB to isolate the sensitive analog traces from the noisy ESP32 RF antenna.
PHASE 02

Firmware & Data Acquisition

Wrote RTOS-based firmware for the ESP32 to handle strict timing requirements. One task sweeps the voltage across the sensor precisely every 10ms, while another task batches the readings and publishes them via MQTT to prevent dropped packets.

C++ FreeRTOS I2C / SPI
> Applied a lightweight digital low-pass filter (moving average) directly on the edge device to smooth 60Hz mains interference before network transmission, saving bandwidth.
PHASE 03

Cloud Backend & MQTT Broker

Set up an AWS EC2 instance running a Mosquitto MQTT broker and a Node.js Express server. The server subscribes to the hardware topics, parses the raw hex payloads into JSON, and stores historical experiments in PostgreSQL.

Node.js MQTT PostgreSQL
PHASE 04

Live Visualization Dashboard

Engineered a React frontend utilizing WebSockets (Socket.io) to receive data from the backend instantly. Implemented high-performance charting with Recharts to draw the cyclic voltammograms at 60fps without browser lag.

React WebSockets Recharts
PHASE 05

System Integration & Calibration

The final step involved calibrating the custom hardware against a commercial $15,000 potentiostat using standard potassium ferricyanide solutions. The prototype achieved 98% accuracy compared to the benchtop standard.

Module 01 / Physical

Analog Front End (AFE)

Interfaces directly with the 3-electrode sensor. Applies a precise sweeping voltage and reads the returning micro-amp current. Uses a TI LMP91000 configured via I2C for programmable gain.

  • → DAC generates excitation waveform
  • → TIA converts current to voltage
Module 02 / Edge Compute

ESP32 FreeRTOS Firmware

Orchestrates the hardware timing. Uses hardware timers to trigger ADC reads exactly every 10ms. Packages raw 16-bit integers into optimized binary structures for network transmission over WiFi.

  • → Strict deterministic timing
  • → WiFi provisioning & auto-reconnect
Module 03 / Transport

MQTT Message Broker

Acts as the central nervous system. Devices publish telemetry to specific topics (`device/{id}/stream`). This pub/sub model decouples the hardware from the backend, ensuring high throughput and easy scaling.

  • → QoS 1 for guaranteed delivery
  • → TLS encryption for secure payload

Node.js Express API

Subscribes to MQTT broker, processes incoming binary payloads into readable JSON, handles authentication, and exposes REST endpoints for historical data fetching.

PostgreSQL Database

Relational storage for user accounts, device metadata, and time-series experiment results. Optimized with indexing on device IDs and timestamps.

React Single Page App

The user interface. Establishes a WebSocket connection to the Node API for live data plotting. Allows researchers to configure sweep parameters and export CSVs.

Key Capabilities

Real-Time Visualization

Chemical reactions happen in milliseconds. The platform processes and graphs data streams at 60 frames per second using WebGL acceleration, allowing researchers to monitor peaks and anomalies instantly.

Battery Operated

Runs for 12 hours on a standard 18650 Li-ion cell thanks to aggressive deep-sleep firmware profiles.

Data Export

One-click export of raw telemetry to CSV/JSON formats, strictly adhering to standard laboratory data compliance.

Instead of physical dials, researchers configure the voltage sweep range, scan rate, and sensitivity directly from the web dashboard. Changes are pushed to the device Over-The-Air instantly.

Engineering Decisions

FreeRTOS (C++) Firmware

Selected over Arduino core for deterministic task scheduling. Allowed separation of precise hardware polling from the unpredictable latency of WiFi transmission.

MQTT Protocol Transport

Chosen over standard HTTP REST. The lightweight binary header of MQTT drastically reduced payload overhead on the edge device and provided built-in connection state handling (Last Will & Testament).

Node.js & WebSockets Backend

The event-driven, non-blocking I/O model of Node is perfectly suited for handling thousands of small, continuous data packets from IoT devices concurrently.

Recharts / Canvas Frontend

Standard DOM-based charting libraries crashed when fed high-frequency telemetry. Switched to a Canvas-based rendering approach within React to maintain smooth UI performance.

Reflections

Bridging the Hardware-Software Gap

Building an end-to-end IoT system is inherently interdisciplinary. A minor bug in the analog circuit design can manifest as corrupted data on the web frontend weeks later.

The biggest technical challenge was managing noise. In early prototypes, the ESP32's WiFi transmissions caused massive voltage spikes on the sensitive analog lines, ruining the data. I solved this by redesigning the PCB ground planes and implementing a firmware constraint that prevents ADC reads during active WiFi transmission windows.

Outcome: The resulting prototype successfully validated the concept of decentralized, low-cost analytical hardware. It demonstrated that complex edge data can be reliably synthesized, transmitted, and visualized in real-time using modern web technologies.
